PROMPT PARA CORREGIR EL ALGORITMO OMS 0 A 5 AÑOS

Necesito corregir el algoritmo de clasificación nutricional pediátrica para pacientes de 0 a 60 meses, usando estándares OMS 2006.

Fuentes de referencia que debe respetar:
- OMS Child Growth Standards 2006 para 0 a 5 años.
- Indicadores a calcular: BMI/Edad (IMC para la edad), HFA (Talla para la edad) y WFA (Peso para la edad).
- Para exceso de peso en menores de 5 años, usar principalmente BMI/Edad. Peso/Edad NO debe diagnosticar obesidad por sí solo.

Datos de referencia:
1. referencia.indicador_antropometrico debe tener:
   BMI: edad_min_meses = 0, edad_max_meses = 60
   HFA: edad_min_meses = 0, edad_max_meses = 60
   WFA: edad_min_meses = 0, edad_max_meses = 60
2. referencia.oms_curva debe tener 6 curvas:
   BMI_M_WHO2006, BMI_F_WHO2006, HFA_M_WHO2006, HFA_F_WHO2006, WFA_M_WHO2006, WFA_F_WHO2006
3. referencia.oms_curva_punto debe tener puntos LMS por sexo, indicador y edad_meses de 0 a 60.

Clasificación BMI/Edad 0 a 60 meses:
- z < -3: Delgadez severa
- -3 <= z < -2: Delgadez
- -2 <= z <= +1: Normal o eutrófico
- +1 < z <= +2: Riesgo de sobrepeso
- +2 < z <= +3: Sobrepeso
- z > +3: Obesidad

Clasificación Talla/Edad 0 a 60 meses:
- z < -3: Talla baja severa
- -3 <= z < -2: Talla baja
- -2 <= z <= +2: Talla normal
- z > +2: Talla alta

Clasificación Peso/Edad 0 a 60 meses:
- z < -3: Bajo peso severo
- -3 <= z < -2: Bajo peso
- -2 <= z <= +2: Peso normal para la edad
- z > +2: Peso elevado para la edad, pero debe mostrarse como alerta de revisión y NO como obesidad automática.

Cambios obligatorios en el código:
1. La función clasificar_zscore debe recibir edad_meses.
2. La consulta a heuristico.condicion debe filtrar por indicador_codigo, id_tipo_condicion = 3, edad_min_meses y edad_max_meses.
3. La clasificación nutricional principal en 0 a 60 meses debe ser BMI/Edad para delgadez, riesgo de sobrepeso, sobrepeso y obesidad.
4. WFA debe mostrarse como indicador complementario, especialmente para bajo peso, pero no debe reemplazar BMI/Edad como diagnóstico principal de exceso de peso.
5. HFA debe mostrarse separado como diagnóstico de crecimiento/talla.
6. El resultado debe devolver por separado:
   - bmi_edad
   - talla_edad
   - peso_edad
   - diagnostico_nutri_texto = bmi_edad.diagnostico
   - diagnostico_talla_texto = talla_edad.diagnostico
   - diagnostico_peso_texto = peso_edad.diagnostico
7. Si edad_meses está fuera de 0 a 60, este algoritmo 0-5 no debe clasificar y debe devolver error controlado o Sin referencia.

Implementar con fórmula LMS:
Si L == 0: z = ln(valor / M) / S
Si L != 0: z = (((valor / M) ** L) - 1) / (L * S)

Validar que los límites no se crucen:
- z = +1 exacto en BMI debe ser Normal.
- z > +1 y <= +2 debe ser Riesgo de sobrepeso.
- z = +2 exacto debe ser Riesgo de sobrepeso.
- z > +2 y <= +3 debe ser Sobrepeso.
- z = +3 exacto debe ser Sobrepeso.
- z > +3 debe ser Obesidad.
- z = -2 exacto debe ser Normal.
- z < -2 y >= -3 debe ser Delgadez o Bajo peso según indicador.
- z < -3 debe ser severo.
