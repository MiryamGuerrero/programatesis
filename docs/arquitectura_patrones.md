# Patrones aplicados en Reuma Nutri

## 1. Arquitectura en capas
- Presentacion: Flutter
- Datos: Supabase
- Logica: FastAPI

## 2. BaaS
- Supabase reduce carga operativa de backend tradicional.

## 3. Microservicio
- FastAPI encapsula calculos clinicos, reglas y aprendizaje.

## 4. Sistema experto
- Reglas con catalogo de acciones y objetivos.

## 5. Sistema adaptativo
- Preferencias aprendidas con consumo + evaluacion.

## Resultado
- Operaciones simples directas al BaaS.
- Operaciones complejas al microservicio.
- Menor latencia en CRUD y alta trazabilidad en decisiones.
